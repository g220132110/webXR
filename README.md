# SEL 社會情緒學習 WebXR VR 體驗 - 使用說明

## 📱 如何使用

### 方法一：手機 + Google Cardboard（推薦）
1. 用手機瀏覽器開啟 `sel-vr-experience.html`
2. 點擊右下角的 VR 眼鏡圖示進入 VR 模式
3. 將手機放入 Cardboard 中
4. 用視線注視按鈕 1.5 秒即可觸發選擇

### 方法二：電腦瀏覽器測試
1. 用 Chrome 或 Firefox 開啟檔案
2. 用滑鼠拖曳可環視四周
3. 用滑鼠點擊按鈕進行選擇

### 方法三：架設到網路伺服器
將檔案上傳到任何網路空間（如 GitHub Pages, Netlify 等），即可分享給學生使用。

## 🎯 六個場景介紹

### 場景 1：自我覺察 (Self-Awareness)
- **環境**：清晨教室氛圍（柔和橙黃色）
- **核心問題**：「坐在這裡的你，現在心裡正發生什麼？」
- **選項**：
  - A: 我說不上來，但有點不舒服
  - B: 我還好，只是有點累
- **教育目標**：不分對錯，先認識自己的情緒狀態
- **邏輯**：兩個選項都進入場景 2（調適）

### 場景 2：自我管理 (Self-Management)
- **環境**：安定的藍色氛圍
- **核心活動**：呼吸引導（動畫圓圈）
- **特殊機制**：按鈕延遲 5 秒才出現，強制停留與調節
- **教育目標**：調整不是控制，是給自己一分鐘
- **文案**：「先讓身體慢一點，不用急著想清楚。」

### 場景 3：社會覺察 (Social Awareness)
- **環境**：走廊灰藍色
- **情境**：「剛剛有人撞到你卻沒道歉，你覺得是？」
- **選項**：
  - A: 他針對我，真沒禮貌！ → 顯示提示「換個角度再看看...」
  - B: 也許他只是心裡也不好受 → 進入場景 4
- **教育目標**：不是叫你原諒，而是先不急著判斷

### 場景 4：人際技巧 (Relationship Skills)
- **環境**：樓梯溫暖色調
- **情境**：「朋友看起來在等你開口，你想怎麼說？」
- **選項**：
  - A: 不要吵，我現在很煩。 → 提示「有時候沉默比爆炸更安全」
  - B: 我今天不太在狀態，可以陪我坐一下嗎？ → 進入場景 5
- **教育目標**：不是要你變會聊天，而是允許自己有界線（I-Message 溝通）

### 場景 5：負責任的決策 (Decision-Making)
- **環境**：夕陽橘色
- **情境**：「訊息已經打好，正想按送出。你會？」
- **選項**：
  - A: 立刻送出，讓對方知道我的不滿！ → 顯示後果畫面
  - B: 先存成草稿，等心情穩了再說。 → 進入場景 6
- **教育目標**：延遲，不是逃避，是成熟的一種形式

### 場景 6：結尾 (Closure)
- **環境**：陽光金黃色
- **文案**：「你已經走完今天的一圈。練習不是變完美，而是變靠近自己。」
- **功能**：重新開始按鈕（重新載入頁面）

## ✨ 我改良的地方

### 相比 ChatGPT 原始劇本的優化：

1. **✅ 簡化互動邏輯**
   - 去除複雜的彈窗系統，改用文字淡入淡出
   - 場景 3、4 的提示更流暢，不打斷體驗
   - 場景 5 的後果顯示更自然

2. **✅ 不依賴大量素材**
   - 使用純色漸層天空盒取代 360 圖片
   - 每個場景有獨特色彩氛圍（橙黃→藍→灰藍→溫暖→橘→金黃）
   - 可立即使用，無需準備圖片檔案

3. **✅ 優化凝視互動體驗**
   - 1.5 秒凝視時有綠色填充動畫
   - 按鈕懸停時有放大效果
   - 視覺回饋清晰

4. **✅ 場景轉換流暢**
   - 使用 opacity 動畫淡入淡出
   - 文字提示自動消失
   - 無突兀的畫面跳轉

5. **✅ 文字可讀性高**
   - 使用大尺寸、高對比度文字
   - 適合 VR 環境閱讀
   - 中文支援良好

6. **✅ 完整技術實現**
   - 單一 HTML 檔案，無外部依賴
   - 所有互動邏輯完整運作
   - 跨平台相容（手機、電腦、VR 頭盔）

7. **✅ 保留教育核心**
   - 完整保留 SEL 五大向度結構
   - 文案幾乎完全保留 ChatGPT 的優秀設計
   - 教育目標清晰明確

## 🔧 如果你想添加真實素材

### 添加 360 背景圖片
找到對應場景的 `<a-sky>` 標籤，例如：
```html
<!-- 原本 -->
<a-sky color="#FFE5B4" opacity="0.95"></a-sky>

<!-- 改成 -->
<a-sky src="bg_classroom_morning.jpg"></a-sky>
```

### 添加環境音效
在場景中加入音效：
```html
<a-entity id="scene-1" visible="true">
  <a-sound src="sfx_clock_soft.mp3" autoplay="true" loop="true" volume="0.3"></a-sound>
  ...
</a-entity>
```

### 添加點擊音效
在按鈕上加入：
```html
<a-entity ... id="scene1-btn-a">
  <a-sound src="click.mp3" on="click"></a-sound>
  ...
</a-entity>
```

## 🎓 教學建議

1. 確認學生手機可開啟網頁

## 🐛 疑難排解

**Q: 看不到 VR 按鈕？**
A: 某些瀏覽器需要 HTTPS 才能啟用 VR 模式，建議上傳到支援 HTTPS 的網路空間。

**Q: 凝視游標沒反應？**
A: 確認已進入 VR 模式，並將視線中心對準按鈕 1.5 秒。

**Q: 場景 2 的按鈕沒出現？**
A: 這是設計功能，需等待 5 秒讓學生做呼吸練習。

**Q: 手機效能不佳？**
A: 可以降低畫面複雜度，或改用較新的手機。
